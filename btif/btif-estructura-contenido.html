Estructura de contenido y componentes de interfaz

1. Estructura de contenido​

Se reporta que el sitio contiene una única página llamada Inicio. Esto confirma que la solución está construida como una landing page de una sola ruta principal, donde las secciones internas reemplazan la navegación multipágina.

Tipo de contenidoEstadoObservación
Página: InicioActivoPágina principal de la landing BTIF. Editada con Bricks Builder.
EntradasNo documentadas como parte del sitioNo participan en la landing según la información recibida.
GaleríaEntrada visible en el menú adminDebe verificarse si es CPT, plugin o recurso auxiliar. No se documenta como contenido público validado.

Modelo editorial​

El modelo editorial es simple: el administrador entra a la página Inicio, abre el editor Bricks, edita secciones visuales y guarda cambios. La mayoría de secciones se administran visualmente desde el builder.

2. Arquitectura funcional de la landing​

La landing está organizada en secciones verticales. Cada sección cumple una función específica dentro del flujo de comunicación: captar atención, explicar el programa, mostrar evidencia, presentar beneficios y convertir mediante formulario.

3. Componentes de interfaz​

Aunque el código de Bricks no fue exportado, la revisión visual permite documentar componentes reutilizables que probablemente están construidos como contenedores, bloques o elementos del builder.

ComponenteUsoRecomendación de mantenimiento
HeaderNavegación principal y CTA superior.Mantener enlaces como anclas internas y validar responsive móvil.
HeroPrimer impacto visual y mensaje de campaña.Optimizar imagen de fondo y asegurar contraste suficiente.
Cards informativasComunican beneficios o conceptos.Unificar estilos para reutilización.
Contadores / métricasEvidencian resultados.Validar que números sean editables sin alterar diseño.
GaleríaPrueba visual y memoria del evento.Optimizar imágenes, usar lazy loading y dimensiones definidas.
Bloque de aliadosRespaldo institucional.Administrar logos en tamaños consistentes.
FormularioConversión principal.Medir envío con GTM y validar mensajes de éxito/error.
FooterCierre institucional.Mantener enlaces legales y redes actualizadas.

Patrón de cards​

Las cards de la landing siguen un patrón: icono o recurso visual, título, descripción y contenedor con sombra o fondo. Este patrón debe mantenerse como componente reutilizable para evitar inconsistencias visuales.

Formulario como punto de conversión​

La sección Unirme al BTIF es el punto de conversión más importante. Debe estar integrada con medición de eventos, validación de campos y mensaje claro de confirmación.

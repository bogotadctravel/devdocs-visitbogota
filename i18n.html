CódigoIdiomaArchivo

enIngléslocales/en.json

Claves de traducción — locales/{lang}.json​

NamespaceEjemplos de claves
commonback, confirm, seeAll, retry, select
navhome, audioguides, whatToDo, whereSleep, whereEat, language, footer
homewelcome, subtitle, featured, exploreMore, audioguidesSubtitle
planstitle, subtitle, itinerary, withWhom
notFoundtitle, message, cta

Función t() — src/components/i18n.js​

import { t } from 'src/components/i18n'

// Uso básico
t('home.welcome', lang)        // → "Bienvenido a Bogotá"
t('common.seeAll', 'en')       // → "See all"

// Fallback: si la clave no existe en el idioma solicitado → retorna el valor en español

Strings dinámicos desde la API​

El thunk fetchAllWords() obtiene strings de UI desde la API y los guarda en languageReducer.words.

// Acceso en componentes:
const words = useSelector(selectWordsLang)
// words es un objeto con strings indexados numéricamente: words[lang][index]

dispatch(setLanguage('en'))  // Cambia a inglés

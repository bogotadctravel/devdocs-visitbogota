2. Resumen ejecutivo​

El Catálogo de Entretenimiento Visit Bogotá es un sitio construido sobre Drupal 11 cuyo modelo de operación se basa en una estructura sencilla y mantenible: un tipo de contenido principal, una taxonomía de categorías, Views para la generación de listados y un tema personalizado para la capa visual.

La arquitectura del sitio evita complejidad innecesaria. La taxonomía controla la navegación, Views resuelve los listados y los templates Twig del tema transforman el contenido en componentes visuales como tarjetas, carruseles, mapas y fichas de marca.

3. Arquitectura general​

La arquitectura funcional del sitio puede entenderse como una cadena de renderizado Drupal estándar: el usuario selecciona una categoría, Drupal resuelve el término de taxonomía, Views obtiene los contenidos asociados, el view mode define la representación y Twig produce el HTML final.

La página de detalle de Marca extiende este flujo con componentes adicionales: mapa embebido, iconografía SVG inline y un bloque de contenido relacionado renderizado como carrusel Swiper.

Patrones observados​

  • Uso de Drupal Core primero: Node, Taxonomy, Views, Blocks, Menus, Media, Metatag y Pathauto.
  • Separación entre contenido y presentación mediante View Modes.
  • Reutilización de la vista nativa Taxonomy Term para evitar crear una vista por cada categoría.
  • Personalización frontend en Twig, especialmente para tarjetas y carruseles.
  • Uso de imágenes optimizadas mediante estilos de imagen.

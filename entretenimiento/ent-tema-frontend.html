Tema, Twig y arquitectura frontend

1. Tema personalizado y plantillas Twig​

El tema activo es Catálogo Theme, basado en Olivero. El Theme Debug del HTML permite identificar varias sobrescrituras y plantillas utilizadas para construir el frontend.

TemplateEstadoUso
themes/custom/catalogo/templates/views/views-view.html.twigDetectadoSobrescritura general de Views.
themes/custom/catalogo/templates/views/views-view-unformatted--contenido-relacionado.html.twigDetectadoGenera la estructura Swiper para contenido relacionado.
themes/custom/catalogo/templates/content/node--marca--teaser.html.twigDetectadoConstruye la tarjeta resumida de Marca.
node--marca--full.html.twig o node--marca.html.twigInferidoLa estructura del detalle de Marca tiene clases personalizadas; debe validarse con el código fuente.
field.html.twigCore/OliveroRender de campos sin template personalizado.
field--node--title.html.twigCoreRender del título del nodo.
field--text-with-summary.html.twigOliveroRender del body con resumen.

Tarjeta de Marca​

El HTML observado muestra una tarjeta compacta con imagen, título y botón. Esta tarjeta es reutilizada por el carrusel de contenido relacionado y posiblemente por otros listados.

2. Arquitectura frontend​

El frontend está compuesto por tres vistas públicas principales: página de inicio, página de categoría y página de detalle de marca. Las capturas compartidas confirman una línea visual consistente: hero amplio, uso de tarjetas, grids responsivos, breadcrumb y footer institucional.

ComponentePáginaImplementación probable / detectada

BreadcrumbCategoría / MarcaEasy Breadcrumb o breadcrumb del core.

Convenciones CSS observadas​

Las clases siguen una convención cercana a BEM, con bloques como content y teaser, modificadores como content--first y elementos como content__item.

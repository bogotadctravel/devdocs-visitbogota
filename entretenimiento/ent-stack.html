Stack tecnológico e infraestructura

1. Componentes del stack​

ComponenteVersión / tecnologíaObservaciones
CMSDrupal 11.3.13Núcleo de administración, contenido, taxonomías, Views y APIs.
PHP8.3.21Drupal recomienda mantener soporte activo. El informe sugiere PHP 8.4+ para soporte continuo.
Servidor webLiteSpeedServidor HTTP utilizado por el entorno.
Base de datosMariaDB 10.6.23Soporte JSON disponible.
Tema públicoCatálogo ThemeTema personalizado basado en Olivero.
Tema administradorClaro 11.3.13Tema administrativo de Drupal.

CachéRender/page cache deshabilitadaEstado típico de desarrollo. Debe revisarse para producción.

2. Hallazgos del informe de estado​

TipoHallazgoImpactoAcción sugerida
ErrorDirectorio de sincronización de configuración no presenteImpide exportar/importar configuración desde UI/Drush según el flujo estándar.Definir $settings['config_sync_directory'] en settings.php.
AdvertenciaDrupal no actualizado; versión 11.4.1 disponibleRiesgo de quedar fuera de cobertura de seguridad futura.Planificar actualización de núcleo.
AdvertenciaTwig development mode activadoReduce rendimiento y expone sugerencias de templates en HTML.Desactivar en producción.
AdvertenciaMarkup caching disabledRender cache, dynamic page cache y page cache omitidas.Activar cachés en producción.
AdvertenciaJS Cookie se carga desde CDNPosible observación de privacidad y dependencia externa.Instalar biblioteca local en /libraries/js-cookie.
RevisiónTrusted host patterns configuradosBuena práctica de seguridad.Mantener catalogoentretenimiento.visitbogota.co y ambientes válidos.

GrupoMódulos relevantesUso

AdministraciónAdmin Toolbar, Extra Tools, SearchMejoras del backend.
ViewsViews, Views UI, CTools ViewsConsultas, listados y bloques.
SEOMetatag, Pathauto, Redirect, Simple XML Sitemap, TokenSEO, URLs y sitemaps.
MultilenguajeLanguage, Content Translation, Configuration Translation, Interface TranslationSoporte de idiomas y traducciones.

SEO, rendimiento y caché

1. SEO y metadatos​

El sitio cuenta con una base SEO robusta gracias a la instalación de Metatag, Pathauto, Redirect y Simple XML Sitemap. Además, cada Marca posee un campo de metatags para personalizar la información de búsqueda y redes sociales.

MóduloFunción
MetatagGestión de metatags por entidad, ruta y vista.
Metatag: Open GraphControl de títulos, descripciones e imágenes para Facebook y otras redes.
Metatag: Twitter CardsMetadatos para tarjetas de Twitter/X.
Metatag: HreflangSoporte multilingüe y etiquetas alternates.
Metatag: VerificationVerificación con buscadores y servicios externos.
PathautoAlias automáticos de URL.
Redirect / Redirect 404Gestión de redirecciones y errores 404 frecuentes.
Simple XML SitemapGeneración de sitemap XML y soporte hreflang.

Recomendaciones SEO​

  • Instalar y configurar Schema.org Metatag, recomendado por el informe de estado.
  • Usar datos estructurados LocalBusiness cuando la marca corresponda a un establecimiento físico.
  • Completar alt text en todas las imágenes de Marca.
  • Validar canonical y hreflang en páginas de categoría y marca.
  • Definir imagen social por defecto para marcas sin imagen personalizada.
  • Evitar que categorías desactivadas aparezcan en sitemap o menú público.

2. Rendimiento, caché y activos​

El HTML de la ficha de Marca muestra buenas decisiones de renderizado de imágenes y componentes, pero el informe de estado revela configuraciones de desarrollo que deben corregirse para producción.

ElementoEstado observadoEvaluación
Imagen detalleEstilo wide, loading eagerAdecuado para hero principal de la ficha.
Imagen teaserEstilo teaser, loading lazyAdecuado para carruseles/listados.
Imagen Teaser large330 x 240Optimiza tarjetas de listado.
SwiperHTML renderizado con controles y bulletsImplementación visual flexible.
IconosSVG inlineEvita dependencias externas de icon fonts.
Render cacheDeshabilitadaDebe activarse en producción.
Twig debugActivoDebe desactivarse en producción.
APCuNo activadoRecomendado para mejorar rendimiento.

Checklist de producción​

  • Desactivar Twig debug y Twig development mode.
  • Activar render cache, dynamic page cache y page cache.
  • Revisar agregación/minificación de CSS y JS.
  • Instalar js-cookie localmente si el módulo lo requiere.
  • Configurar APCu si el hosting lo permite.
  • Verificar que imágenes originales no se sirvan en listados.
